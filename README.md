# SR BOUTIQUE

Single-file storefront with built-in admin control panel.

## Open the site

Once GitHub Pages is enabled, the site lives at:
`https://albusaidit.github.io/srboutique-website/`

## Open the admin panel

- Click the gear icon at the bottom-left of the page
- Or press **Ctrl + Shift + A**
- Or visit `?admin=1` (e.g. `…github.io/srboutique-website/?admin=1`)
- Or triple-click the footer copyright

Default admin password: `sr2026` (change it from Settings after first login).

## Updating

Edit `index.html` directly on GitHub (pencil icon) and commit. The site
re-deploys automatically in ~30 seconds.
